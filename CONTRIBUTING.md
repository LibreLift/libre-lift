# Contributing to LibreLift

This project welcomes the time and efforts of the community.

To get started, fork the repo and walk through the [setup guide](./docs/setup.md) to get the app running on your local machine. Ensure that you have a mobile device to test app builds on, or can access iOS/Android simulators.
