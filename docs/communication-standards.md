# Communication Standards

## Communication Platform

Project communication with take place on GitHub Discussions. It will be used for the main communication functions:

- Announcements
- PR review requests
- Issue assignment requests
- All other project communication

Response times for development dependent tasks such as issue assignment and review requests will be responded to **within 48 hours**. That's our commitment.

## Project maintainers and decision making 

Project-wide decisions are made by the project maintainers, with input from the entire project community. No decisions will be made by maintainers without first consulting with the larger project community. While it is not practical for every decision to full satisfy everyone, we believe that we can generally get things right and remain united as a community by making decisions together.

## Issue communication

Communication on specific issues happens through two mediums: **Issue comments** and **Issue labels**. Some issue labels are meant to be directed at the issue author/assignee, and others at the rest of the community, e.g. "question" is applied when someone else reading the issue needs clarification from the issue author, and "awaiting response" is applied when the issue author/assignee needs a reply from someone else.
